# Kairos v1 project page

纯静态网站，无需安装依赖或构建。

## 上传与发布
1. 创建公开仓库 `kairos_v1`。
2. 上传本文件夹内的 `index.html`、`assets` 文件夹及本说明，不要只上传 ZIP，也不要额外嵌套一层 kairos_v1 文件夹。
3. 仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。
4. 网址为 https://你的用户名.github.io/kairos_v1/ 。

## 本地查看
双击 index.html，或用本地静态服务器打开。

## 修改内容
- 页面文字、样式、问答及跳转时间均在 index.html。
- assets/backpack.mp4 是用于网页播放的无声压缩版视频，原视频未被修改。
- assets/framework-updated.png 为最新框架图。
- 演示答案为人工整理的流程示例，非模型实测输出；0、4、11秒为近似跳转点。
- 作者名单、论文正式名称、论文下载与代码链接未确认，因此没有虚构入口。
- 指标来自团队提供的前期数据。公开发布前应补全对应测试设置，并确认视频公开使用权限。
- 本包未自动创建GitHub仓库或发布网站。


## Livestream demo
The livestream product names and five time intervals were supplied by the research team. The original MOV is retained locally and excluded from the website ZIP. Upload livestream-products.mp4, not livestream-products.mov. The demo plays precomputed intervals without live inference.
